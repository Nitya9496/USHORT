# uShort — Next-Gen 3D URL Shortener (Vercel Ready)

This is the **optimized, single-repository Vercel version** of uShort. It contains the complete Next.js 14 App Router application with real-time 3D Three.js graphics, Framer Motion springs, glassmorphic analytics, and built-in Serverless API Route Handlers.

## 🚀 1-Click Vercel Deployment

1. Open your terminal in this directory:
   ```bash
   cd c:\ushortx
   ```
2. Initialize git and push to your GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: uShort production-ready 3D URL Shortener for Vercel"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
   git push -u origin main --force
   ```
3. Go to [Vercel](https://vercel.com/new), select your repo, and click **Deploy**!
   - **Framework Preset**: Next.js (Automatic)
   - **Root Directory**: `./` (Default root)
   - **Zero configuration required!**
